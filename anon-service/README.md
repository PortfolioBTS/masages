# Anon Service (Rust)

Микросервис для криптографически стойкой генерации приватных идентификаторов.
Необязательный: без него Node использует встроенный JS-генератор.

## API

### POST /generate

Возвращает JSON:
```json
{
  "unique_code": "A3F9K2M8",
  "username": "Гость-X7B2Q"
}
```

Если задан `ANON_SERVICE_SECRET`, запрос обязан нести заголовок
`X-Internal-Secret` с тем же значением, иначе `401` с пустым телом.
Сравнение идёт за постоянное время (без раннего выхода на первом
несовпавшем байте).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BIND_ADDR` | `[::]:8080` | адрес прослушивания, строго `IP:порт` (`[::]:8080`, `0.0.0.0:8080`, `127.0.0.1:8080`). Имя хоста не принимается; при неверном значении сервис пишет ошибку и завершается. `[::]` на Linux слушает и IPv6, и IPv4 — это нужно для private networking Railway (в окружениях, созданных до 16.10.2025, он только IPv6) |
| `ANON_SERVICE_SECRET` | не задан | общий секрет с Node — длинная случайная строка. Не задан или пуст — `/generate` доступен без секрета, остаётся только сетевая изоляция |

Node (`server.js`) шлёт `X-Internal-Secret` из своей переменной
`ANON_SERVICE_SECRET` — в обоих сервисах должно быть одно и то же
значение. Адрес сервиса Node берёт из `ANON_SERVICE_URL`; на Railway это
`http://<имя-сервиса>.railway.internal:8080`. Публичный домен сервису не
нужен.

## Запуск

```bash
cargo run --release
```

Docker (двухстадийная сборка, процесс в контейнере — не root):

```bash
docker build -t anon-service anon-service/
docker run --rm -e ANON_SERVICE_SECRET=... -p 127.0.0.1:8080:8080 anon-service
```

`Cargo.lock` в репозитории нет, зависимости выбираются при каждой сборке.
Поэтому в `Cargo.toml` указан `rust-version`, а Dockerfile включает
MSRV-aware резолвер: он берёт версии зависимостей, совместимые с этим
тулчейном. Rust в образе — `1.94`.
