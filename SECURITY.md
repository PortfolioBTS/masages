# Политика безопасности Nyxo

## Реализованная защита

1. **Content Security Policy (CSP)** — nonce-based, запрещает inline скрипты и стили.
2. **CSRF защита** — double-submit cookie pattern.
3. **Rate Limiting** — ограничение попыток входа, регистрации, смены пароля и API.
4. **Magic Bytes** — проверка содержимого загружаемых файлов.
5. **Параметризованные запросы** — защита от SQL-инъекций через pg.
6. **Сессии** — хранятся в PostgreSQL, httpOnly cookie.
7. **WebSocket авторизация** — проверка сессии перед join комнаты.
8. **Защищённая раздача файлов** — только авторизованным пользователям.
